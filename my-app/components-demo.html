这一页的内容全部由两个函数生成：Components.statCard() 和 Components.materialItem()。它们住在 js/components.js。 组件里的样式或结构改一次，主视图和这一页会同时变——这就是「可复用」的意思。

组件一：统计卡片 StatCard

参数只有三个：value（主数字）、unit（单位，可省）、label（说明）。 第一张故意给了很长的说明文字和 5 位数字，用来测「数字撑长会不会挤坏卡片」。

cards.map(Components.statCard) // 传入的每个对象就是一张卡片： { value: '24', unit: '', label: '素材总数' } { value: '3.2', unit: '小时', label: '已听时长' } { value: '12.8', unit: '小时', label: '累计跟读练习时长（含复读次数）' }

组件二：素材列表条目 MaterialItem

素材列表

6 种情况

六条分别是：还没听（0%）、听了一半、听完了（100%）、 视频（🎬）、超长文件名（省略号）、 缺字段（防御性：少传一个字段也不该白屏）。

materials.map(Components.materialItem) // 传入的每个对象就是一条素材： { name: '第03课-连读与弱读.mp3', type: 'audio', folder: '第三课', duration: 754, listened: 588 }
